# Primeira-API
Repositório destinado a versionar os códigos do trabalho "primeira API" na disciplina de programação web.

Rotas disponíveis:

- ALUNOS:

Rota para exibir todos alunos cadastrados:
- /alunos/listar

Rota para exibir um(a) aluno(a) a partir de um ID:
- /alunos/visualizar/:id

Rota para cadastrar um(a) aluno(a):
- /alunos/cadastrar

Rota para atualizar totalmente um(a) aluno(a) a partir de um ID:
- /alunos/atualizarTotal/:id

Rota para atualizar parcialmente um(a) aluno(a) a partir de um ID:
- /alunos/atualizarParcial/:id

Rota para deletar um(a) aluno(a):
- /alunos/excluir/:id

- CURSOS:

Rota para exibir todos cursos cadastrados:
- /cursos/listar

Rota para exibir um curso a partir de um ID:
- /cursos/visualizar/:id

Rota para cadastrar um curso:
- /cursos/cadastrar

Rota para atualizar totalmente um curso a partir de um ID:
- /cursos/atualizarTotal/:id

Rota para atualizar parcialmente um curso a partir de um ID:
- /cursos/atualizarParcial/:id

Rota para deletar um curso:
- /cursos/excluir/:id
